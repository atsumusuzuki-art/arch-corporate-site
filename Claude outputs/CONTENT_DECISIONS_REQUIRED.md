**ずれている点**

- 30万円の意味が違う。サイトは「判断の範囲（経営レイヤー）」、フィロソフィーは「ARCH が実働を伴う標準の立ち上げ」。
- 15万円の位置づけが違う。サイトは誰でも選べる運営プラン、フィロソフィーは「院内に実働責任者がいる場合だけ ARCH から提示する」商品。
- 7か月目以降の継続（月額15万円）がサイトにない。
- 商品名が「伴走」と「立ち上げ支援」で違う。

**変えた場合の影響（変更箇所の目安）**

- `app/services/external-manager/page.tsx` の `PLANS`（金額・名称・説明・含まれる内容）と、ページの説明文（metadata の description にも金額が入っている）
- 同ページの構造化データ（`offers`。Google に渡る金額情報）
- `app/services/visit-dental-consulting/page.tsx`「支援期間と費用」の文言
- `CLAUDE.md` 2.3節の料金、`docs/arch-hp-baseline-spec-2026-08-10.md` 8章（2026-08-22改定）
- 自走型15万円をサイトに載せる場合は「ARCH から提示する」性質と矛盾しないか（載せない選択肢もある）
