## 1. 料金

**今回も変更していません。** サイト表記・構造化データ・metadata の金額はすべて 2026-08-22 改定のままです。

| 項目 | 現在のサイト表記 | ARCHフィロソフィー Ver.2.0 |
|---|---|---|
| 月額15万円 | 外部事務長｜運営伴走。運営レイヤー。医院スタッフだけで基本運営が回る状態をつくる | 自走型立ち上げ支援：月額15万円×6か月。院内に実働責任者がいる場合だけ ARCH 側から提示する。値引き商品ではない |
| 月額30万円 | 外部事務長｜経営伴走。経営レイヤー。院長の重要な経営判断まで扱う | 標準立ち上げ支援：月額30万円×6か月。ARCH が実働を伴う標準商品 |
| 継続 | 記載なし（両プランとも最低6か月） | 継続外部事務長：原則7か月目以降 月額15万円。期間だけで自動移行しない |
| 初期費用 | 両プランとも「支援範囲に応じて別途見積もり」 | 記載なし |
| 訪問歯科コンサルティング | 期間・費用とも個別見積もり | 立ち上げ支援（上記30万／15万×6か月）に相当する可能性あり。新規施設立ち上げ・採用実働・分院・法人化・M&A・補助金・大規模制作は別途設計 |

**ずれている点**

- 30万円の意味が違う。サイトは「判断の範囲（経営レイヤー）」、フィロソフィーは「ARCH が実働を伴う標準の立ち上げ」
- 15万円の位置づけが違う。サイトは誰でも選べる運営プラン、フィロソフィーは「院内に実働責任者がいる場合だけ ARCH から提示する」商品
- 7か月目以降の継続（月額15万円）がサイトにない
- 商品名が「伴走」と「立ち上げ支援」で違う

**変えた場合に触る箇所**

- `app/services/external-manager/page.tsx` の `PLANS`（金額・名称・説明・含まれる内容）とページの説明文
- 同ページの `metadata.description`（金額が本文に入っている）
- 同ページの構造化データ `offers`（Google に渡る金額情報）
- `app/services/visit-dental-consulting/page.tsx`「支援期間と費用」
- `CLAUDE.md` 2.3節、`docs/arch-hp-baseline-spec-2026-09.md` 10章
- 自走型15万円をサイトに載せる場合、「ARCH から提示する」性質と矛盾しないか（載せない選択肢もある）

| 二本柱：外部事務長（運営伴走・経営伴走）／訪問歯科コンサルティング | 初回適性相談（無料）→ 標準立ち上げ支援／自走型立ち上げ支援 → 継続外部事務長。大型の個別案件は別途設計 |
