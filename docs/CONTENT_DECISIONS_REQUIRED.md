# 解決済みの項目（2026年9月14日・商品/料金/契約）

## 1. 料金 → 確定・サイト反映済み

| 商品 | 料金 | 期間 | 位置づけ |
|---|---|---|---|
| 初回適性相談 | 無料 | — | 組むべきかを確認する場。診断書・実行計画書・資料作成・同行・実装責任は含まない |
| 標準立ち上げ支援 | 月額30万円（税別） | 最低契約期間6か月 | **主商品。** ARCHが実働を伴う |
| 自走型立ち上げ支援 | 月額15万円（税別） | 最低契約期間6か月 | **条件付き。** 院内に実働責任者がいる場合に限り、ARCH側から提案する。値引き商品ではない |
| 継続外部事務長 | 月額15万円（税別）を基本 | — | 立ち上げ・運営が安定した後も経営価値が残る場合 |
| 卒業 | — | — | 経営レイヤーも医院内で担えるようになれば契約終了 |

- 初期費用：案件・支援内容により別途見積もりとする場合がある。固定額は掲載しない。架空の値引き表示はしない
- 遠方での現地支援：交通費（飛行機・新幹線・特急を要する場合）と、必要な場合の宿泊費を別途。オンライン支援にも対応
- 旧「月額15万円＝運営伴走／月額30万円＝経営伴走」の2プラン構造は**廃止**。復活させない

正は `lib/site.ts` の `PRICING`。詳細は `docs/ARCH_PRODUCT_CONTRACT_POLICY_2026-09.md`。

## 2. 商品構成 → 確定

初回適性相談（無料）→ 標準立ち上げ支援／条件付きの自走型立ち上げ支援 → 継続外部事務長 → 卒業。
新規施設立ち上げ・採用実働・分院・法人化・M&A・補助金・大規模制作などの大型案件は別途設計。ただし当初合意した支援範囲を後から別料金に変更しない。

サイトでは「30万 VS 15万」の価格比較を主役にせず、①標準 →②条件付きの自走型 →③安定後の継続、の順で見せます。
ARCHの自己定義（`lib/site.ts` の `BRAND.definition`）は「ARCHは、訪問歯科を入口に、歯科医院の立ち上げ・運営・承継を支える外部事務長会社です。」で固定。立ち上げ専門会社に見せません。

ページ名（「訪問歯科コンサルティング」／TOPの「訪問歯科支援」）は、URLを変えない前提で現行のままとしました。

## 3. 契約条件 → 確定

| 項目 | 確定内容 | サイト掲載 |
|---|---|---|
| 最低契約期間 | 6か月（「6か月で必ず終わる」とは表現しない） | 掲載する |
| 更新 | 6か月経過後は原則自動更新 | 掲載する |
| 終了 | 以後はARCH・医院いずれからも1か月前の申し出で終了可能 | 掲載する |
| プラン・料金の変更 | 期間の経過だけでは自動的に変更しない。医院ごとに個別判断 | 掲載する |
| 最低契約期間内の中途解約 | 打ち切りは可能だが、残存期間分の料金の支払義務は残る | **掲載しない（内部契約条件）** |

> 注記：`docs/ARCH_PRODUCT_CONTRACT_POLICY_2026-09.md` は運用基準の記録であり、契約書の条文そのものではありません。契約書・申込書の作成／改訂と法務レビューは別工程です。
