# コラム執筆・改稿ルール（非公開の運用資料）

このファイルはサイトには公開されません。`/columns` に載せる記事を書く・直すときの基準です。

## 1. 記事の型

1 記事 = `lib/columns/<slug>.tsx` 1 ファイル。`meta`（記事情報）と `Body`（本文）を export する。
新しい記事を足すときは、このファイルを 1 つ作り、`lib/columns/index.ts` に 1 行 import を追加するだけ。
レイアウトは `app/columns/[slug]/page.tsx` が共通で持つので、記事側でレイアウトを書かない。

## 2. 構成

- **結論を最初に置く**。`meta.conclusion` に 1〜2 文で書き、記事の冒頭に表示される
- 見出し（`<h2>`）は 3〜6 個。見出しだけ読んで筋が通る状態にする
- 最後に「まとめ」を置き、確認すべき点を箇条書きにする
- 本文の最後に関連サービス（外部事務長 / 訪問歯科コンサルティング）への内部リンクを 1 つ入れる
- 目安は 1,600〜2,600 字

## 3. 書く内容

- 現場で実際に起きることを具体的に書く。抽象的な一般論を並べない
- **確認済みの事実と、意見・解釈を文の中で分ける**。意見は「と考えています」「という印象があります」と明示する
- 診療報酬・医療制度・法律・統計に触れるときは、厚生労働省など公的な一次資料に当たる。当たれないなら書かない
- **出典のない数字を作らない**。「◯％」「◯割の医院が」は、一次資料か自社の確認済み実績がある場合だけ
- 未確認のことは記事に出さない。「たぶんこうだろう」を書かない
- 患者・スタッフ・医院・施設が特定できる情報は書かない。事例は地域と状況の抽象度で止める

## 4. 使わない表現

過去の記事にあった以下の表現は使わない。同種の言い回しも避ける。

- 「患者だけを診る歯医者は淘汰される」のような、断定的な将来予測
- 「絶対に利益は上がりません」のような、例外を認めない断定
- 「悪質ブローカー」のような、特定の業態への強い断罪
- 「売上の20〜40％を永久に吸い取られる闇」のような、出典のない数字と煽り
- 「本物のコンサルティング」「圧倒的な営業力」のような、自社を持ち上げる形容
- 「唯一の解決策」「秘密」「〜の真実」「もう終わりです」といった見出し
- 読者を不安にさせて動かす書き方全般

## 5. 表記

- 「歯科医院」「訪問歯科」「施設」「院長」「スタッフ」を基本語彙にする
- 横文字のブランド造語を作らない
- 断定を弱める必要がある箇所は「〜する医院が多い」ではなく「〜という相談を受けることがある」と、
  自分が見た範囲であることが分かる書き方にする

## 6. 公開前チェック

- [ ] 冒頭に結論があるか
- [ ] 出典のない数字が残っていないか
- [ ] 断定と意見が分けて書かれているか
- [ ] 特定できる固有情報が残っていないか
- [ ] 関連サービスへの内部リンクが入っているか
- [ ] `published` / `modified` が実際の日付になっているか
